# 正式二维插画地图页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的 `honglou-garden-image-v1` 作为《红楼小灶》正式 `/garden` 页面，接入正式前端与已核验内容，并达到发布前质量标准。

**Architecture:** 以现有二维插画底图、归一化六景配置和 HTML 覆盖层为唯一地图实现。正式页面复用图片地图的视图状态、热区、场所面板和可访问性逻辑；食典、小书匣及食笺的真实入口通过明确的数据映射接入，未核验关系继续显示演示说明。

**Tech Stack:** 现有正式前端的路由和构建工具；HTML/CSS/ES modules；本地图图片资源；Playwright 浏览器验证。

**Spec:** `outputs/honglou-garden-image-v1/docs/design/visual-review.md`、`outputs/honglou-garden-image-v1/docs/design/verification.md`、`docs/superpowers/plans/2026-09-28-红楼小灶-前端设计与功能总计划.md` 第 5.5 节。

## Global Constraints

- 正式 `/garden` 使用二维插画，不能以图片伪装三维或提供 360° 旋转。
- 仅使用已核验的六景人物、场所与原著说明；菜品关系未经核验时不开放“入小灶”。
- 维持参考图的绢白、深胭脂、旧金、白墙灰瓦与斜俯视构图；桌面右栏目标宽度 213px，正文不整体缩小。
- 图片、标签、热区与视图状态必须分层；固定页头、控件和阅读栏不随图片移动。
- 原图、`sources/` 和既有三维样板保持只读、不覆盖；正式地图资源采用独立正式命名。
- 页面标注“首版六景，艺术化布局”，不宣称精确原著复原。

## Review Focus

- 从缩放状态打开或关闭阅读栏后，地图中心和倍率应保持稳定。
- 图片载入失败时，用户仍应能通过居所一览阅读六景。
- 小屏幕键盘、触摸双指和系统字体放大时，控件不应横向溢出或彼此遮挡。
- 未核验的菜品关系不能因为错误数据或深链接而开放制作入口。
- 路由切换并返回 `/garden` 时，应恢复可预期的总览或已保存的浏览状态，且不残留旧版本 UI。
