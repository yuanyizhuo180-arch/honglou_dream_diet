# 大观园三维白模 v2 布局说明

状态：待用户审阅。第四版视觉方向已确认；本白模的空间、体量和移动构图尚未确认。所有同步项目资料保持只读，本文为独立版本。

## 设计与实现

真正的 Three.js 网格、正交相机、光照与阴影。默认固定斜俯视平移；按用户本次确认增加独立“旋转看园”模式，固定仰角、水平360度环看；按钮再切回平移。复位恢复角度0、目标(0,0,4)、100%缩放与平移模式。缩放70%–190%，目标偏移各轴±35单位。相机向量初始(0,135,165)，旋转只改变水平方向。

网页静态独立部署，路径 `/garden`；`garden-data.json`集中管理空间，`scene.js`负责建模、投影及相机，`app.js`负责控件、面板和降级。保留原资料库网站，未覆盖原有 honglou-web 或 v4 图片。未为了白模强制引入 React 构建系统；后续可把场景和配置移入现有游戏组件。

配色：绢白#f7f0e5、灰瓦#93948b、素墙#eae6dc、温木#ad9478、水绿#aac6c1、深胭脂#813846、少量旧金#b39868。标题与标签用宋体系统字；正文以真实HTML排版。遵循天工“疏密相间、曲径障景”，以分组竹林、香草和少量树保留识别性；素地、庭院与局部池面共同承担留白。第四版30%/10%是视觉参考，不是测量复现承诺。

## 交互、降级与手机

真实文字标签与模型选择相同节点，模型使用射线拾取；拖动阈值6px，拖动后不触发选择。两指缩放，触点取消清理；滚轮与按钮缩放。Tab与Enter/空格可操作HTML按钮；地图获得焦点后方向键平移，旋转模式左右键转向，+/-缩放，Home复位。浮层与其他控件焦点不会触发地图快捷键；Esc关闭说明或面板，焦点返回触发入口。关闭面板保留相机。

手机390×844采用更宽的三维取景，控件放到底部单排、列表默认折叠；面板为底部浮层且内部滚动，最高52dvh。旋转后有标签避让算法；超出视野的标签隐藏，居所列表仍可进入所有节点。总览六标签均展示。

`?fallback`可检查二维降级；WebGL建立失败或上下文丢失后保留SVG与居所列表。加载提示明确显示，全部三维依赖保存在本地，运行无需CDN。演示入口不接真实AI和数据库，未核验菜品不配置制作入口。
