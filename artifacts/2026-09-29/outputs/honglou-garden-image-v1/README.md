# 红楼小灶 · 二维插画交互地图

预览：http://localhost:5175/garden/
原图与底图对照：http://localhost:5175/comparison.html

本地启动：在本目录运行 `python3 -m http.server 5175`。
全部资源本地保存，无Three.js/WebGL、AI或数据库依赖。

右栏从精细版320px改为213px（66.56%），地图占用释放出的宽度。正文16px，不整体缩小字号。手机版使用可滚动底部面板。关闭面板保留倍率、地图中心；到边缘时执行边界约束。

图片范围70%–300%，100%是当前视口的等比适配。平移、滚轮/双指、按钮、键盘及建筑热区均可操作。六节点资料沿用精细版，只将白模语境改为插画语境。

底图由内置imagegen编辑工具清理，原图副本和处理PNG均保存于assets。该过程不是逐像素无损修复：局部纹理和被遮挡部分有细微差别，详见对照页。放大不会增加源图中不存在的真实细节。

交付为首版六景、艺术化布局。待用户审阅底图修补、标签位置和窄栏效果。
